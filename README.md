# Smart Farming Website

A static website about modern and eco-friendly farming. It explains farming basics, the purpose of the site and farming methods, and includes an image gallery, a farming video and a farmer information form.

**Live Demo:** https://reshmithakanameni-hub.github.io/farming-website/

## Features
- Navigation bar with Home, About, Purpose, Methods, Gallery and Farmer Form sections
- Hero section with a call-to-action button
- About Farming section covering organic farming, irrigation, modern techniques and crop production
- Purpose section with cards: Learn, Explore, Understand and Create Awareness
- Image gallery (tractor in field, aquaponics, eco-friendly farming, modern technology, smart harvesting)
- Farming video section
- Farmer Information Form with name, email, farming experience, farming method and message fields
- Custom green farming theme styled with CSS

## Built With
- HTML5
- CSS3

## Project Structure
- `index.html` - main page
- `farming.css` - styles
- `images/` - gallery images and video

## Run Locally
1. Download or clone this repository.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Note
This is a personal learning project. All names and contact details are sample data. The farmer form is frontend only and does not store any data.
