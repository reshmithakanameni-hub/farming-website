🌱 Smart Farming Website

A static website about modern and eco-friendly farming. It explains farming basics, the purpose of the website and different farming methods. It also includes an image gallery, a farming video and a farmer information form.

Live Demo: https://reshmithakanameni-hub.github.io/farming-website/

✨ Features

- Navigation bar with Home, About, Purpose, Methods, Gallery and Farmer Form sections.
- Hero section with a call-to-action button.
- About Farming section covering organic farming, irrigation, modern techniques and crop production.
- Purpose section with four cards: Learn, Explore, Understand and Create Awareness.
- Image gallery featuring tractor in field, aquaponics, eco-friendly farming, modern technology and smart harvesting.
- Farming video section.
- Farmer Information Form with name, email, farming experience, farming method and message fields.
- Custom green farming theme styled using CSS.

🛠️ Built With

- HTML5
- CSS3

🚀 Run Locally

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open "index.html" in a browser.
4. Alternatively, use the VS Code Live Server extension.
